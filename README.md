# 云智洁 3D 数字孪生定位系统

基于 Three.js 的室内定位数字孪生演示系统，数据来自云智洁品质模块（北京中海广场 355 个功能区）与工牌扫码轨迹（2026-10-27 全天 643 条 / 7 名员工）。

## 在线访问

GitHub Pages：`https://chapuine.github.io/`

## 功能

- **建筑物视图**：3D 楼栋（中楼 35F / 南楼 21F / 北楼 6F / 地下 4F），拖拽旋转 / 缩放 / 视角预设，点击楼栋查看签到、楼层完成率、进出明细，楼层条点选 3D 高亮
- **楼层视图**：2D 平面图按功能区着色，hover/click 显示到访员工与停留时长，完成情况统计面板
- **人员视图**：项目级作业轨迹 3D 回放（时间线 + 播放控制），区域停留排行与分楼栋路线表
- **实时监控**：esmap 风格 3D 室内图，员工实时位置 + 目的地导航（距离/方向）+ 电子围栏进出告警
- **Admin 配置**：项目信息 / 楼栋轮廓编辑 / 功能区位置画布 / 信标组绑定 / 电子围栏 / 后端接口契约

## 工程结构

```
index.html         入口（桥接 window.DB）
style.css          全局样式
app-1.js ~ 7.js    应用逻辑（路由 / Admin / 实时引擎 / 楼层平面 / 3D 场景 / 楼栋视图）
data-core.js       核心数据（项目/楼栋/信标/员工/实时/围栏）
data-zone-1~4.js   功能区位置数据（60 键）
data-tracks-1~4.js 员工轨迹数据（7 人）
```

## 数据说明

- 项目：北京中海广场（朝阳区建国门外大街光华里 8 号），中楼 B1 35F/150m、南楼 B2 21F、北楼 B4 6F、地下 B3 4F
- 全部数据源自用户提供的原始附件，前端 JSON 驱动；生产环境由后端实现 `app-2.js` 中接口契约替换为 fetch 调用
