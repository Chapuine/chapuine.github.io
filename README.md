# 云智洁3D数字孪生定位系统

基于 three.js 的室内蓝牙信标定位 3D 数字孪生展示系统。

## 功能
- 实时监控：电子工牌 + 蓝牙信标实时定位，3D 室内地图即时显示
- 建筑物视图：多楼栋 3D 建模、楼层切换、指南针、自动旋转
- 楼层视图：2D 平面图按楼层筛选作业信息
- 人员视图：员工当日全项目作业路线回放
- 管理配置：项目信息 / 楼栋建模 / 功能区位置 / 信标绑定 / 电子围栏

## 技术栈
- three.js（Three.js r128，CDN 引入）
- 数据：真实扫码明细（2026-10-27，643 条）
- 单文件 HTML，无构建依赖

访问 https://Chapuine.github.io 查看在线演示。
